##  Sobre o projeto

Este projeto consiste no desenvolvimento de uma **calculadora utilizando React**.

A aplicação permite que o usuário informe dois números, escolha uma operação matemática e visualize o resultado diretamente na tela.

O projeto foi desenvolvido com o objetivo de praticar conceitos básicos de **React, JSX, componentes, estados e eventos**.

---

##  Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 🔢 Entrada de dois números
- 📋 Seleção da operação através de um `<select>`
- 🧮 Cálculo do resultado
- 🧹 Botão para limpar os campos
- 📱 Interface simples e organizada

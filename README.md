# Calculadora em React

Projeto de uma calculadora simples desenvolvida em React.

## Funcionalidades

- Inserir o primeiro número
- Inserir o segundo número
- Escolher uma operação
- Calcular o resultado
- Limpar os campos

## Conceitos aplicados

Neste projeto foram utilizados:

- React
- JSX
- useState
- Eventos como onChange e onClick
- Condicionais com if e else if
- HTML
- CSS
- Tag select para escolher a operação

## Operações disponíveis

- Soma (+)
- Subtração (-)
- Multiplicação (*)
- Divisão (/)

## Objetivo

O objetivo do projeto é praticar a criação de componentes em React, o uso de estados e a interação com o usuário.
